QueueLess – Smart Digital Token System

A college project that replaces physical queues at the college office, fee counter, library and canteen with digital tokens, live tracking and waiting-time estimates.

The problem

  • Students stand in long lines at fee counters and offices.
  • No idea how long the wait will be or when it is their turn.
  • Crowded corridors and wasted class time.

The solution

  • Choose a service and get a digital token in seconds.
  • Track position, people ahead and estimated wait live.
  • Get notified when you are next and when it is your turn.
  • Staff call, complete or skip tokens from an admin dashboard.

Features

What is included

Student

  • Register / login
  • Generate token, cancel
  • Live position + wait time
  • QR Token Pass, receipt
  • Ratings, notifications, SMS simulator

Admin

  • Call / complete / skip
  • Counters and services
  • Token history, reports
  • Analytics, search, CSV
  • Scan token at counter

Public

  • Live Queue board
  • Campus TV display
  • Dark mode
  • Responsive layout

Built with

  • HTML, CSS, JavaScript
  • localStorage as the data store
  • qrcode-generator (MIT)
  • Custom SVG illustrations

Honest limitations

  • This version is frontend-only. Data lives in each browser's localStorage and is not shared between devices.
  • Passwords are hashed in the browser, which is demo-grade, not real security. A production version needs a backend and database.
  • SMS is simulated – no real messages are sent.
  • Waiting time is a simple estimate (people ahead × average service time ÷ counters), not a prediction model.
